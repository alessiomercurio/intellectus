# Phase 4 — Report

Goal: the **one** deliverable of the research: concise, precise, every claim traceable. Write in the **user's language**. `03-analysis.md` is the input only; don't copy it wholesale.

## Rules
1. **Answer first**: the opening lines answer the main question.
2. **Only what serves a sub-question.**
3. **Every claim cited** `[S#]`; uncited = your inference (say so) or remove it.
4. **No new facts** beyond `03-analysis.md`.
5. **B-sources labelled** as ideas from a different context.
6. **Confidence** for main conclusions: High (several reliable, compatible sources) · Medium (one solid source or needs adaptation) · Low (weak, contradictory, B-only).
7. **Limits and gaps** stated plainly.
8. **Concise**: short sentences, tables for comparisons, no narration of the process. Length is free: as long as the answer needs, no padding.

## Structure: `04-report.md`

```markdown
# <Title>
## Short answer
3–5 lines, key citations, confidence.
## <Sub-question 1>
...
## Ideas from related sources (if any)
## Limits and gaps
## Sources
- [S1] Authors (Year). *Title*. Venue. URL/DOI
```

List only cited sources, same IDs as `02-sources.md`.

## Quick check before review
Short answer answers the main question · every Q has a section or a gap · `[S#]` ↔ Sources match · no hard constraint broken · numbers match the analysis.
